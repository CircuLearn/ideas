# 🛡️ Clan Hub – CircuLearn

Welcome to the **Circulearn Clan** — a peer-driven community of passionate students growing together through open-source, project-based learning, and mutual mentorship.

---

## 🎯 Mission

To create a supportive, inclusive space where students:
- Learn together and grow in technical domains they care about
- Contribute to open-source and real-world projects
- Support each other through code reviews, feedback, and peer mentorship

---

## 📌 How It Works

- **Domain Freedom**: Explore fields like Web Dev, DevOps, AI/ML, or anything you love
- **No strict hierarchies**: Everyone is both a learner and contributor
- **Real Collaboration**: Work on projects, submit PRs, review code, and ideate together

## 🤝 How to Join

1. Fork this org and raise a PR to the `members` repo with your profile.
2. Join the Discord/Slack community (link coming soon).
3. Pick your domain and start collaborating!
